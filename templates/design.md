# 의정부 경전철 보고서 디자인 가이드라인 (templates/design.md)

본 문서는 보고서의 웹 레이아웃 디자인 시스템 및 파이썬 시각화 차트 생성을 위한 프리미엄 테마 규칙을 정의합니다.

## 1. 디자인 컨셉
- **Rich & Premium**: 일반적인 공공기관 테이블 중심의 레이아웃을 탈피하고, 대시보드 형태의 글래스모피즘(Glassmorphism) 및 정돈된 다크/라이트 하이브리드 테마를 지향합니다.
- **Data-First Visibility**: 핵심 통계 수치가 가장 먼저 시선을 끌도록 큰 폰트(Huge Metric Cardinal)와 마이크로 애니메이션(hover) 효과를 부여합니다.

## 2. 색상 시스템 (Color Palette)
일반적인 원색(빨강, 파랑 등) 대신 조화롭고 세련된 테마의 HSL 계열 및 슬릭한 테두리 색상을 사용합니다.

| 분류 | 역할 | 색상 코드 (Hex) | 적용 예시 |
| :--- | :--- | :--- | :--- |
| **Primary** | 주조색 (어두운 배경/텍스트) | `#0f172a` | 대제목, 메인 헤더, 다크 테마 카드 배경 |
| **Secondary** | 보조색 (설명 텍스트/보조 선) | `#64748b` | 서브타이틀, 축선, 설명 텍스트 |
| **Accent Blue** | 포인트 강조 (승차량, 활성 요소) | `#3b82f6` | 주요 데이터 라인, 강조 테두리 |
| **Accent Cyan** | 포인트 강조 (하차량, 서브 지표) | `#06b6d4` | 비교 데이터 라인, 강조 배지 |
| **Success / Up** | 증가 또는 긍정 요인 | `#10b981` | 증가 화살표, 안전/양호 데이터 |
| **Danger / Down**| 감소 또는 주의 요인 (이상치) | `#ef4444` | 감소 화살표, 특이값 강조 |
| **Light BG** | 기본 배경색 (라이트 모드) | `#f8fafc` | 전체 페이지 백그라운드 |
| **Card BG** | 콘텐츠 블록 배경 (글래스모피즘) | `#ffffff` / `#1e293b` | 정보 박스 배경 (오파시티 85% 이상) |

## 3. 타이포그래피 (Typography)
- **웹 폰트**: Inter, Outfit, NanumGothic 또는 AppleGothic (로컬 한글 지원)
- **제목 (h1, h2)**: Outfit/NanumGothic, Bold, 자간 줄임, 어두운 남색 계열
- **본문**: Inter/NanumGothic, Regular, 15px, 라인높이 1.6
- **차트 폰트**: 한글 깨짐 방지를 위해 `NanumGothic` 또는 OS별 기본 한글 폰트(`AppleGothic`, `Malgun Gothic`)를 탐색 후 사용하며, 차트 내 대제목은 14pt, 축 제목은 11pt, 틱 텍스트는 9pt로 고정합니다.

## 4. 파이썬 차트 생성 세부 규격 (Matplotlib)
- **이미지 포맷**: PNG (고해상도 투명 배경 지원)
- **해상도 (DPI)**: 150 DPI 이상 (권장 200 DPI)
- **차트 물리 크기**: 800px * 480px (가로:세로 = 5:3 비율 권장)
- **여백 (Padding)**: `plt.tight_layout()` 호출을 통해 데이터 라벨과 틱 텍스트의 잘림 현상을 완전 방지합니다.
- **스타일 디테일**:
  - grid: 활성화하되, 보조선 색상은 아주 옅은 보조색(`#e2e8f0` 또는 다크 테마 시 `#334155`)에 대시선 스타일(`--`)을 적용합니다.
  - legend: 모서리를 둥글게(fancybox) 처리하고 투명도를 주어 글래스 느낌을 유지합니다.
  - line: 선 차트의 경우 line 두께를 `2.5`로 두껍게 하고 marker를 포인트에 매칭해 모던하게 표현합니다.
  - bar: 막대 차트의 경우 모서리 끝부분을 부드러운 컬러 단색으로 칠하고, 3D 입체 효과는 절대 사용하지 않는 플랫(Flat Design)을 유지합니다.
